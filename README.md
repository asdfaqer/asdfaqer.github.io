# Fengtao Wang &mdash; Personal Website &amp; Portfolio

Source repository for [asdfaqer.github.io](https://asdfaqer.github.io).

## Features
- **Hero Showcase**: Minimalist typography hero with static chevron and smooth navigation.
- **Scroll-Triggered Project Carousel**: Interactive 3D carousel with themed cards linking to GitHub repositories.
- **Interactive AI Demos**: Dedicated standalone pages and lightweight expandable in-page previews for the Discrete Autoencoder (`autoencoder.html`) and Chess CNN (`chess.html`).
- **Resume Integration**: Embedded modal preview and direct PDF download for Fengtao Wang's resume.
- **Custom Color Palette**: Styled with `#4E1F6E`, `#3E3E75`, `#45A9A9`, and `#98E8DE`.

## Local Development
Run a local server with PyTorch support:
```bash
python server.py --port 8080
```
Open `http://localhost:8080` in your browser.
