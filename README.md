# Fengtao Wang &mdash; Personal Website &amp; Portfolio

Welcome to the source repository for [asdfaqer.github.io](https://asdfaqer.github.io).

## Features
- **Hero Showcase**: Big typography hero with animated chevron and smooth transitions.
- **Scroll-Triggered Project Carousel**: Interactive 3D carousel with themed backgrounds linking to GitHub repositories (Discrete Autoencoder, Chess CNN, TroupeTTS, Mind Map, Crazyhouse Bots).
- **Interactive 4K Downscroller Rhythm Game**: Playable browser arcade port of the 4K Downscroller rhythm game with Web Audio API synthesizer, accuracy judgment, combo counter, and victory confetti.
- **Resume Integration**: Embedded modal preview and direct PDF download for Fengtao Wang's resume.
- **Custom Color Palette**: Styled with `#4E1F6E`, `#3E3E75`, `#45A9A9`, and `#98E8DE`.

## Local Development
Run a local static server:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in your browser.
