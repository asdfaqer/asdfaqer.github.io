Supervised and Reinforcement Learning

There are two main categories of ML: Supervised Learning, where the model is trained on many inputs with the correct outputs already provided. These models tend to be used in image classification, translation, and language modeling tasks.

The other is Reinforcement Learning, where the model is trained on a reward system and improves itself using that as a guide. While reinforcement learning can be more costly, it isn't limited by the quality of data humans can provide it. Thus allowing it to outperform humans and other traditional algorithms in various board games like Chess and Go, as well as play some video games with pro-level gameplay like StarCraft and Dota 2. Even tasks like protein folding use reinforcement learning algorithms.
